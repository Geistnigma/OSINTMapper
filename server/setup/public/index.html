Installation d'OSINTMapper

Trois réglages, puis l'instance est prête. Cette page n'écoute que sur cette machine.

1 · Où ranger les enquêtes

Tout tient dans ce seul dossier : c'est lui, et lui seul, qu'il faudra sauvegarder. Un volume chiffré est un bon choix.

2 · Accès

L'adresse publique ne sert que derrière un reverse-proxy TLS. Laissez vide pour un usage local.

3 · Comptes

Les comptes supplémentaires peuvent aussi être créés plus tard depuis l'écran d'administration.
